本机检查使用 Python 3.12；GitHub Actions 另覆盖 Ubuntu / Windows × Python 3.10 / 3.12。QQ 写操作通过平台替身检查请求参数和生命周期，不能把这类测试称为已经验证腾讯服务端的实际撤回结果。

## 真实 OneJev 验证

健康响应确认 `OneJev-4B.Q4_K_M`、`llama.cpp`、`qev-labels-v2`。先检查默认 yes/no 问题，再比较明确中文正反选项与其他短问题；最终采用原生 `criteria.true/false` 明确区分实施违规行为和正常交流、引用、求助、举报或劝阻。
